# E-Commerce Dataset Analysis

## Internship Project - Cognetix Technology

This project analyzes e-commerce sales data using Python, Pandas, Matplotlib, and Seaborn to identify revenue trends, customer orders, and top-performing products.

---

## Objective

The main objective of this project is to:
- Analyze customer orders and purchasing trends
- Study sales revenue patterns
- Identify best-selling products
- Determine high-revenue regions/categories
- Visualize business insights using charts

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

---

## Dataset

Dataset Source:
https://www.kaggle.com/datasets/vijayuv/onlineretail

Dataset File:
OnlineRetail.csv

---

## Features

- Data Loading using Pandas
- Data Cleaning and Validation
- Revenue Calculation
- Product-wise Sales Analysis
- Country-wise Revenue Analysis
- Monthly Revenue Trend Analysis
- Customer Orders Analysis
- Bar Chart Visualization
- Pie Chart Visualization
- Trend Analysis

## Key Insights

- Certain products generated significantly higher sales volume.
- A few countries contributed the majority of total revenue.
- Revenue trends increased during specific months.
- Customer purchasing behavior varied across products and regions.
- Data visualization helped identify important business patterns.
